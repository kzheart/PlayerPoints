## 回滚方法

归档内的 `rollback.py` 是应急脚本，**本轮未执行**。回滚必须先正常停止两服，保存当时最新的数据库，再在事务内移除两个新增触发器及函数、将 schema 标记恢复为 1、安装备份旧 JAR 和配置，最后启动两服。脚本保留回滚时的余额与流水，不恢复过期账户快照。不能只替换旧 JAR：mulan.2 不接受 schema 2。
